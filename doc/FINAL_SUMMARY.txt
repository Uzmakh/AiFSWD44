                         CUSTOMIZATION EXAMPLES
================================================================================

CHANGE AUTOPLAY SPEED:
  In cars.html line 190:
    autoplay: 4000,  # Change to 2000 for 2 seconds

CHANGE BUTTON COLOR:
  In style.css line 335:
    color: #0077ff;  # Change to #ff0000 for red

DISABLE AUTOPLAY:
  In cars.html line 190:
    autoplay: false,  # Disables auto-rotation

ADD MORE SLIDES:
  In cars.html, duplicate:
    <li class="glide__slide">
      <img src="https://images.unsplash.com/photo-ID?w=800" />
    </li>

CHANGE BANNER HEIGHT:
  In style.css line 305:
    height: 500px;  # Change to 600px for taller
