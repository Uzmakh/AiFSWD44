## 🎯 Configuration Options Available

```javascript
// In cars.html, easily modify:
type: "carousel"              // Loop mode
startAt: 0                    // Starting slide
perView: 1                    // Slides visible
autoplay: 4000                // Auto-rotation speed
hoverpause: true              // Pause on hover
animationDuration: 800        // Animation speed
keyboard: true                // Keyboard support
bound: true                   // Smooth boundaries
dragThreshold: 80             // Desktop drag
swipeThreshold: 80            // Mobile swipe
touchRatio: 0.5               // Touch sensitivity
```

## 💡 Common Customizations

### Change Autoplay Speed (1 line)
In `cars.html` line 190:
```javascript
autoplay: 2000,  // 2 seconds instead of 4
```

### Change Button Color (1 line)
In `style.css` line 335:
```css
color: #ff0000;  // Red instead of blue
```

### Disable Autoplay (1 line)
In `cars.html` line 190:
```javascript
autoplay: false,  // Manual navigation only
```

### Add More Slides (copy & paste)
In `cars.html`, duplicate a slide:
```html
<li class="glide__slide">
  <img src="https://images.unsplash.com/photo-NEW-ID?w=800" />
</li>
```
